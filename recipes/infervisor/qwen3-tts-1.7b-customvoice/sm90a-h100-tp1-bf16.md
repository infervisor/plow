# qwen3-tts-1.7b-customvoice — sm90a-h100-tp1-bf16

Status: **emits, serves; production gates in progress**. Reference:
`infervisor/qwen3-tts-1.7b-customvoice:sm90a-h100-tp1-bf16`.

Qwen3-TTS 12Hz 1.7B CustomVoice, BF16 as published: a 28-layer Qwen3 talker
over dual-stream rows (text token + 16-code frame), the 5-layer code predictor
sampling codebooks 1..15 in one aux program per decode rung, and the
Qwen3-TTS-Tokenizer-12Hz decoder as `codec.pkt` (the same codec as Breeze TTS 2),
streamed through stateful codec steps. Served through the standard speech API
(9 preset voices, 10 languages + auto, instructions).

Streaming replies trim the packet-declared leading silence (`stream.onset_trim_*`,
`PLOW_TTS_ONSET_TRIM=0` streams every sample): the first byte is then the first
audible sample, which needs the second frame (`PLOW_TTS_STREAM_FIRST_FRAMES=2`).

The command blocks below are generated from the recipe TOML by
`scripts/render_recipe.py`; edit the TOML, not the blocks. Prose outside
the markers is hand-written.

### Sampling default and intelligibility (WER)

The packet's default sampling is temperature 0.7 on the talker and the code predictor, top_k 50,
repetition penalty 1.05 (speech profile `qwen3_tts`); a request can override any of them. The
published config (temperature 0.9) makes the model babble on ~0.7% of Seed-TTS EN utterances,
and the metric is a per-utterance mean. Adopted by the user over three alternatives measured
with the official `run_wer.py` (Whisper large-v3; GT audio 2.14%), same prompts, seed 0:

| config | WER 1 rps | WER 20 rps | UTMOS | HF reference WER |
|---|---|---|---|---|
| T 0.9, top_k 50 (published) | 2.00% | 2.78% | 4.066 | 1.85% |
| **T 0.7, top_k 50 (default)** | 1.35% | 1.92% | 4.150 | 2.18% |
| T 0.5, top_k 20 | 1.07% | 1.95% | 4.221 | 0.96% |
| T 0.9, top_k 10 | 1.19% | 1.90% | 4.210 | 2.97% |

Spec method on the default (3 seeds x 120 s, Poisson): WER 1.203% at 1 rps (n=335, target
<= 1.50%; T 0.9 measured 1.804%), 2.269% at 20 rps (n=1088, target <= 2.67%; T 0.9 2.129%),
UTMOS 4.138 at 1 rps (median of the seed means 4.166/4.134/4.138; target >= 4.07; T 0.9 4.073).

Numerics vs HF are gated by the greedy / teacher-forced code match, not by WER.

### Codec PCM vs the official decoder (known miss)

Whole-decode PCM of the 16 official-reference code cases against the official FP32 decoder
(CPU) misses the 1e-5 relative-L2 gate on this recipe's codec route (split-bf16 wgmma convs):
3.3e-5 to 3.6e-5 on speech cases, 7.9e-5 on the shortest window, 4.6e-4 relative on silence
(2e-8 absolute). The miss predates the ragged wgmma tiles, which stay within 2.5% of it per case.
An earlier capture on a different (more precise) codec route measured ~6e-6. Speech
intelligibility is gated by tts_cer and WER instead.
